# Connector Snap Stack — The kitchen-table bills night

*2026-10-19 · fifth stack*

**[Lower My Bill](https://goodturn-mcp.pages.dev/lowermybill)** *(new)* · **[Zeno Household](https://zenonest.com)** *(new)* · **[Gmail](https://mail.google.com)** · **[Google Calendar](https://calendar.google.com)** — running in **Claude Desktop**

A US household working through its recurring bills, one Desktop conversation: find the latest internet, mobile and insurance bills in Gmail, get Lower My Bill's provider-specific call script for each and its reminder to call before a promotional rate ends, check in Zeno Household whether the savings change next month's cash-flow forecast and leave a budget note for a partner, then put the call reminders on Google Calendar. Two new connectors that know the negotiation playbook and the household's numbers, two proven ones that hold the bills and the dates, with Claude carrying the list between them. The calls themselves stay with the person.

*Status: composed, not yet field-tested against a live set of bills. If you run it, send a Field Report (see CONTRIBUTING).*
